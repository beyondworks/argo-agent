# Argo

프롬프트 한 줄로 만드는 **AI 직원 회사**. 폴더 단위 기억으로 AI 직원에게 일을 시키는 데스크톱 앱입니다.

> 이 저장소는 **설치파일 배포 전용**입니다. 앱 소스 코드는 비공개입니다.

## 다운로드

최신 버전은 **[Releases](https://github.com/beyondworks/argo-agent/releases/latest)** 에서 받으세요.

| 운영체제 | 설치파일 |
|---|---|
| macOS (Apple Silicon · M1~) | `Argo_*_aarch64.dmg` |
| macOS (Intel) | `Argo_*_x64.dmg` |
| Windows | `Argo_*_x64-setup.exe` (또는 `.msi`) |

## 설치 — 첫 실행 안내

현재 빌드는 코드 서명 전 단계라, 처음 실행할 때 운영체제 보안 경고가 뜹니다. **정상이며 안전합니다.** 아래대로 한 번만 허용하면 됩니다.

### macOS
1. `.dmg`를 열어 **Argo**를 `응용 프로그램`으로 드래그합니다.
2. 처음 실행 시 *"확인되지 않은 개발자"* 경고가 뜨면:
   - Argo 앱을 **우클릭 → 열기** → 다시 **열기**를 누릅니다.
   - 또는 **시스템 설정 → 개인정보 보호 및 보안** 하단의 *"확인 없이 열기"* 를 누릅니다.

### Windows
1. `*-setup.exe` 를 실행합니다.
2. *"Windows의 PC 보호"* (SmartScreen) 화면이 뜨면:
   - **추가 정보** → **실행** 을 누릅니다.

## 업데이트
